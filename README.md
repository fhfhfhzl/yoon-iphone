# YOON's iPhone
팬메이드 가상 아이폰 웹 시뮬레이터. 공식 앱이나 실제 사적 휴대폰 데이터가 아닙니다.

## GitHub Pages
1. 새 공개 저장소를 만들고 `index.html`을 루트에 업로드합니다.
2. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
3. 배포된 URL을 열어 확인합니다.

## 사진
토르 사진을 사용 허락 및 출처를 확인한 후 `thor.jpg`로 같은 폴더에 추가하면 홈 배경에 나타납니다.

## 게시물
`index.html`의 `posts` 초기 데이터를 확장하거나 별도 게시물 관리 기능을 추가할 수 있습니다. 현재는 사진·원문 업로드를 기다리는 빈 게시물 화면입니다.
